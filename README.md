# СТЛЧК

Интернет-магазин стульев: каталог товаров, корзина и оформление заказа.

## Технологии

Чистые HTML, CSS и JavaScript, без фреймворков.

## Структура проекта

```
├── index.html
├── favicon.svg
├── css/
│   └── style.css
├── js/
│   ├── data.js     — данные о товарах
│   ├── render.js   — отрисовка каталога
│   ├── cart.js     — логика корзины и localStorage
│   └── order.js    — форма оформления заказа
└── images/         — изображения товаров
```

## Функциональность

- Каталог товаров с карточками (название, цена, кнопка «Добавить в корзину»).
- Корзина: добавление и удаление товаров, изменение количества, автоматический пересчёт суммы.
- Корзина сохраняется в `localStorage` и восстанавливается при обновлении страницы.
- Оформление заказа в модальном окне (имя, фамилия, адрес доставки, телефон), по кнопке «Создать заказ» появляется сообщение «Заказ создан!».
- Адаптивная вёрстка (flex/grid + медиазапросы) для ноутбуков, планшетов и смартфонов.

## Запуск

Открыть `index.html` в браузере, либо поднять локальный сервер в корне проекта, например:

```bash
python3 -m http.server
```

и перейти на `http://localhost:8000`.
